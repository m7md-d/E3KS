# E3KS — اعكس

أداة تعكس الهوية البصرية لملفات المستندات: تبدّل الألوان والخطوط دون أن تكسر الملف.

**ابدأ من [.claude/CLAUDE.md](.claude/CLAUDE.md).**

## الحالة

المراحل ١ و٢ و٣ منجَزة: المحرّك يفحص ويبدّل ويعاين ويتحقّق، ويدعم **Word
وPowerPoint**، وتطبيق macOS يعمل بالعربية والإنجليزية.

## التشغيل
```bash
cd packages/e3ks_engine && dart pub get && dart test
```
