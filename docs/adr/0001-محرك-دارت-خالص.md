# ADR 0001 — المحرّك بـ Dart خالص، لا Python وقت التشغيل

**الحالة:** معتمَد · 2026-09-04

## السياق
المنطق قائم في سكربتات Python (`_lab/`) تعتمد `lxml`. المطلوب تطبيق Flutter لـ macOS
ثم الويب لاحقًا.

## القرار
يُعاد بناء المنطق في حزمة Dart خالصة (`archive` + `xml`). لا مفسّر Python يُشحَن ولا يُستدعى.

## البدائل المرفوضة
- **شحن Python مع التطبيق:** حجم كبير، هشاشة في المسارات والأذونات على macOS، ومستحيل على الويب.
- **`Process.run` على Python المثبَّت عند المستخدم:** يعتمد على بيئة لا نملكها. يخالف وعد «يعمل دائمًا».
- **Rust عبر FFI:** أداء أفضل لكنه يضاعف سلسلة البناء بلا حاجة فعلية عند هذا الحجم.

## العواقب
- إعادة كتابة المنطق، ومعها فرصة لتصحيح ما تعلّمناه (`02` §3 و§4).
- الاختبار يصير أسرع: `dart test` بلا Flutter وبلا Xcode.
- دعم الويب يبقى مفتوحًا بلا عمل إضافي في المحرّك.
